# Estrutura de Dados e Algoritmos em C

Repositório voltado à implementação de algoritmos de busca e ordenação e estruturas de dados utilizando a linguagem C.

## Sobre o projeto

O projeto reúne implementações de algoritmos e estruturas fundamentais da computação, explorando técnicas de organização, armazenamento, pesquisa e manipulação de dados.

Cada implementação busca demonstrar o funcionamento das estruturas e dos algoritmos, considerando sua lógica, operações e características.

## Algoritmos e Estruturas Implementadas

### Algoritmos de Pesquisa
- Pesquisa Sequencial
- Pesquisa Binária

### Algoritmos de Ordenação
- Algoritmos de ordenação e organização de dados.

### Estruturas de Dados
- **Pilha (Stack):** estrutura baseada no princípio LIFO (Last In, First Out).
- **Fila (Queue):** estrutura baseada no princípio FIFO (First In, First Out).
- **Árvore Binária:** estrutura hierárquica para organização e manipulação de dados.

## Tecnologias

- Linguagem C

- Git

## Objetivo técnico

Explorar diferentes estratégias de pesquisa, ordenação e organização de dados, compreendendo o funcionamento das estruturas e suas aplicações no desenvolvimento de software.
